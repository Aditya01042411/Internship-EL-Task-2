 ## 📊 Customer Churn & Retention Analysis | Power BI

Developed an interactive **Power BI dashboard** to analyze customer churn, retention, repeat purchases, loyalty programs, and Customer Lifetime Value (CLV).

**Tools Used:** Power BI, Power Query, DAX, Data Modeling.

**Key Highlights:**
- Cleaned and transformed customer data using Power Query.
- Created DAX measures for churn rate, CLV, and repeat purchase rate.
- Analyzed customer segments, promotional impact, and loyalty performance.
- Evaluated store and sales channel performance.
- Built a 4-page interactive dashboard with KPIs, charts, and slicers.

**Key Results:** 24.50% Churn Rate | 95.50% Repeat Purchase Rate | 39.30% Promotional Transactions.

**Outcome:** Identified high-value customers, retention opportunities, and actionable strategies to improve customer loyalty and reduce churn.
